# Nearby Drink Picker 🧋

A web application that helps users randomly choose a nearby drink shop.

## Features

- 📍 Get user's current location
- 📏 Calculate distance using the Haversine Formula
- 🧋 Display nearby drink shops
- 🎲 Randomly pick a drink shop
- 🔍 Filter by distance
- 🟢 Show only open stores

## Tech Stack

- HTML
- CSS
- JavaScript
- Geolocation API
