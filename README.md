Drink Picker
附近飲料店隨機選店助手

專案介紹

不知道今天要喝哪一家？

Drink Picker 是一個利用 Google Places API 搜尋附近飲料店的小工具，
可以依照距離篩選、隨機推薦店家，
並提供品牌菜單與 Google Maps 導航。

---

功能

- 搜尋附近飲料店
- 自動依距離排序
- 距離篩選
- 隨機推薦
- 收藏品牌
- 收藏品牌快速查看附近店家
- Google Maps 導航
- 品牌菜單
- 飲品 / 配料 / 甜度冰塊
- 飲品分類快速跳轉

---

技術

- HTML
- CSS
- JavaScript
- Google Maps JavaScript API
- Google Places API (New)
- LocalStorage

---

專案架構
